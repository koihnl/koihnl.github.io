OPPO手机电脑ADB卸载预装流氓软件完整教程（免Root、USB调试）

一、手机端：开启USB调试（ColorOS全版本通用）

1. 打开开发者模式

  1. 打开「设置」→ 关于本机/关于手机 → 版本信息
  2. 连续点击版本号7次，输入锁屏密码，提示「已进入开发者模式」

2. 开启USB调试关键开关

返回设置：

  • ColorOS13/14/15：设置 → 其他设置 → 开发者选项
  • ColorOS16：设置 → 系统与更新 → 开发者选项

必须打开3个开关：

  1. USB调试（核心）
  2. USB安装
  3. 【可选】OEM解锁（部分新机型不打开电脑识别不到设备）

弹出安全警告全部点允许/确定

二、电脑端：安装ADB工具（Windows）

  1. 官网下载安卓SDK平台工具（ADB压缩包），解压到无中文路径（例：D:\adb）
  2. 打开解压文件夹，空白处按住Shift+鼠标右键 → 在此处打开PowerShell/命令提示符
  3. 数据线连接手机，手机弹窗选择传输文件（MTP），手机弹出「允许此电脑USB调试」勾选始终允许+确定
  4. 输入检测命令，验证连接成功：
adb devices

出现一串设备序列号=连接正常；空白/无设备=没开调试/数据线故障

三、核心操作：查询软件包名+卸载命令

方式1：电脑查看全部应用包名（推荐）

adb shell pm list packages

会列出手机所有软件，格式`包名`

精准搜索某款软件（例：浏览器）：

adb shell pm list packages | findstr browser

方式2：手机APP快速查包名

手机安装雪豹速清 → 工具箱-安装包提取-系统应用，直接复制流氓软件包名，不用电脑翻找

两种卸载命令（按需选）

1. 保留数据卸载（后悔可恢复）推荐

adb shell pm uninstall -k --user 0 包名

2. 彻底删除软件+全部数据

adb shell pm uninstall --user 0 包名

示例：卸载OPPO自带浏览器

adb shell pm uninstall -k --user 0 com.heytap.browser

六、重要避坑提醒

  1. 不Root！ADB只是用户级卸载，不修改底层分区，不丢保修、不影响OTA系统更新；
  2. 卸载前优先备份照片、聊天记录，避免意外；
  3. 卸载后想恢复：软件商店直接搜名称重装，或刷机恢复；
  4. 操作完成后，开发者选项可以关闭USB调试，防止电脑随意读写手机；
  5. 不要一次性批量卸载10个以上，卸载3个重启一次手机，排查异常。

七、常见报错解决

  • device unauthorized：手机重新插拔数据线，重新勾选允许USB调试；
  • 卸载命令执行失败：该软件是系统核心组件，只能禁用不能卸载，使用冻结命令：
adb shell pm disable-user --user 0 包名
  • 电脑识别不到手机：换原装数据线、机箱后置USB接口、重装OPPO官方驱动。

核心重要说明

1. 优先选择 禁用冻结，风险远低于卸载，随时可以恢复；

4. 需要升级系统前，请先启用系统更新相关组件。

可行方案分级（按照安全程度从高到低排序）

方案1：系统设置手动限流（零风险，保底首选）

适用场景：ADB disable-user 被系统拦截，返回 new state: default

  1. 设置 → 应用 → 应用管理，找到目标App
  2. 关闭【自启动】、【后台活动】
  3. 关闭全部通知权限
  4. 关闭关联启动、后台联网权限

优点：完全不需要电脑、无系统损坏风险、不影响OTA升级；

缺点：无法隐藏应用图标，仅限制后台弹窗与偷跑。

方案2：尝试 pm suspend 暂停指令（Android13及以上可用）

作用：暂停应用，阻止应用启动，效果接近禁用。

暂停指令：

adb shell pm suspend --user 0 包名

恢复指令：

adb shell pm unsuspend --user 0 包名

注意：新版ColorOS依然可能拦截此指令；执行后测试App是否还能打开。

方案3：Shizuku 进阶方案（无Root，中等风险）

原理：借助Shizuku获取system级权限，绕过普通ADB shell权限限制。

  • 风险提示：存在一定操作门槛；部分最新ColorOS版本依旧封堵；
  • 禁止使用网络上各类“一键精简、破解冰箱”捆绑工具。

❌强烈不推荐方案（风险极高）

  1. 解锁Bootloader获取Root权限：大概率直接失去保修，系统升级极易变砖；
  2. 各类破解版冰箱、黑域深度冻结工具：容易触发系统安全机制，造成无限重启。

ADB 禁用指令返回状态快速识别表

命令返回信息 结果判定 说明
new state: disabled ✅ 冻结成功 应用被禁用，无法主动启动；需要使用时执行启用命令恢复。
new state: default ❌ 冻结失败 ColorOS系统防护拦截指令，软件维持启用状态，重复执行无效。
直接抛出Exception异常 ❌ 执行失败 大概率是命令语法书写错误、参数顺序错误，核对指令格式。
new state: enabled ✅ 恢复启用成功 已经被冻结的软件执行恢复命令，成功解除禁用。

重要语法易错提醒

标准正确格式：adb shell pm disable-user --user 0 包名

常见错误：漏写 0，把包名识别成用户ID，直接抛出异常。

错误示例（你之前执行的错误命令）：

adb shell pm disable-user --user com.nearme.instant.platform
